## About

Fusion Automate project **FA2** — the Arduino firmware for the ESP32 robot car whose build (bill of materials, wiring diagrams, 3D-printed chassis) lives in [FA1](https://github.com/papercodeIN/FA1).

## Repository Structure

```
FA2/
└── Code/
    ├── V_1/
    │   └── V_1.ino
    └── V_2/
        └── V_2.ino
```

## Getting Started

1. Install the **ESP32 board package** in the Arduino IDE
2. Open `Code/V_2/V_2.ino` (latest firmware version)
3. Select your ESP32 board and upload
